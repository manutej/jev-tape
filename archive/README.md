# Archive

Not occupancy. Kept so the trail is not lost.

| Path | Why archived |
| --- | --- |
| `archive/spec-drafts/` | SPEC-v0, overlapping speed specs, changelogs, meta-prompts |
| `archive/wiki-duplicates/` | wiki slugs that repeat a hub (speed-first vs speed-path, ormus-jev-lanes vs three-lanes) |
| `archive/html/` | one-off review HTML (so-what, overlap, durable lattice) |

If a claim in archive contradicts `spec/SPEC-v1-TAPE.md`, the v1 spec wins.

## Environment notes for a cloud container

Chrome needs `VIBIUM_CHROME_ARGS="--no-sandbox --ignore-certificate-errors"` here (root, TLS-inspecting proxy). Not on a laptop. The proxy gives up on an upstream after 30 s and hands Chrome "upstream request failed"; the public demo host the-internet.herokuapp.com cold-starts in ~30 s, so use `scripts/fixture-site.mjs` instead. Parallel shell calls share one working directory: use absolute paths and `git -C`.

# Speed-first cut

Four speeds, cheapest first. Climb only when needed.

1. Code — schema, amounts, dates.
2. One TypeSafe POST — all independent questions together.
3. Generator — only if Choice said needs prose or a patch.
4. Temporal — only if the write must happen at most once, a human may take days, or a job must not rewind.

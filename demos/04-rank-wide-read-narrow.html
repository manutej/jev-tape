Thirty handlers, one request, four worth reading.

The ablation froze 30 real Fineract command handlers. Twenty-six follow one convention so closely that a motif line regenerates them. Four carry an extra dependency and edge, and a few more lean on a missing annotation or a constants class. Scoring all thirty is one judge request, not thirty. Reading the few that scored low is the expensive part, so it happens after the shortlist is on the tape. The explicit pack is 2,089 tokens; the motif plus the shortlist is far less.

The intersection. wiring-and-the-whole factors a family of units into a motif and its deviants. jev-tape ranks wide with one POST and reads narrow with the expensive model. The deviants are the shortlist.

    What the tape shows

    Three cells matter. The first is one Activity with one POST: thirty Score questions in a single request, thirty answers in a single map. The second is code: the threshold reads the recorded map and cuts a shortlist. The third is the expensive read, an Activity that is not a judge call, and it starts only after the shortlist is on the tape. If the worker dies during the read, replay finds the shortlist and does not rank again.

    The twin's rule is the ablation's own convention check. A handler with more than one dependency or edge scores 1; that reproduces the four deviants the manifest lists. No entity scores 2, a constants-class annotation scores 3, and the rest score 4: the motif line regenerates them byte for byte. Move the threshold and the shortlist changes with no new POST. The rank was recorded once.

    The token meter is honest about what is real. The explicit pack's 2,089 is a measured cl100k count. The motif-plus-shortlist figure is an estimate from character counts, labelled as such, because this page does not carry a tokenizer.

    Counterpoint

    A low score is a difference, not a defect. The score checks how far a handler sits from the family convention. It does not know whether the extra dependency is a bug or the one place the convention was wrong. The options note for the symmetry auditor says it plainly: the one service that differs is the review item. Deciding what the difference means is a fork with an open option set, which is an LLM job, not a Jev job.
    The judge here is a twin. Scores come from the handler's wiring, deterministically, with the same wire shape and contract checks as the real client: five levels, one request, one answer map. No key, no network. A live TypeSafe call is a claim this page does not make.

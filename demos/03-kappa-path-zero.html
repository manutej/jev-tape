Two Moneys walk into a pushout. No judge is called.

The toy bank has two classes named Money. One keeps long amountCents, the other double amount, and the report module reads both. Gluing them along a junction is a pushout: a computable amalgamation that always exists. When two identified names carry different signatures, a lint called κ fires. All of that is arithmetic on names, so it runs as code. This page never sends a request, and the counter that proves it stays at 0.

The intersection. wiring-and-the-whole says a collision is a diagnostic on the quotient map, not an obstruction. jev-tape says a deterministic check is path 0: no TypeSafe, no Temporal. A pushout with a lint is exactly that.

What the tape shows

Every cell on this tape is a code cell. Parsing two files, building the junction, computing the pushout, and running the κ lint are all deterministic functions of the source text. The routing table says what that means: path 0 is code, no TypeSafe, no Temporal. Nothing here is a question for a judge, so nothing here is recorded as an Activity, and the POST counter never leaves zero.

Identify amountCents with amount and κ fires with the two signatures the witness recorded: a field of type long and a field of type double. Identify currency with currencyCode and both sides are String, so the merge is silent and correct. Identify nothing and the glue along an empty junction is the disjoint union: four fields, no collision.

The disabled button is the point. Wrapping a deterministic check in a judge call, or in a Workflow, is listed as illegal in the speed spec. Path 0 items never appear in TypeSafe logs.

Counterpoint

κ is a lint on the quotient, not semantics. It compares signatures of identified names. It does not know that cents and dollars differ when both are stored as long, and it would let that merge through in silence. A silent merge is not a correct one; κ only catches the contradictions that are visible in the types.
The judge here is a twin, and it is never called. This page loads the same twin runtime as the other demos, with the same wire shape and contract checks as the real client, and makes zero requests to it. No key, no network. The zero on the counter is a measurement of this page, not a claim about the real client.

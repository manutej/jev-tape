What the tape shows

Every cell here is an Activity with no POST mark. The witness is a Python script: it builds the pushout, enumerates the cocones, transports the edges, and reports booleans. A deterministic check does not need a judge, but it does need a record, because a crash between check 8 and check 9 must not run check 8 again. Temporal reuses recorded results; it does not recompute them.

Replay proves it on the ring. The first k nodes relight with a dashed reused ring and the replayed counter climbs; the rest light solid as they are computed for the first time. The POST counter never leaves zero. If the checks had been judge calls, the same shape would hold: a replay reuses the recorded answer map and asks nothing.

Then the rung. Thirteen green booleans are a fact; the word demonstrated on the claims ladder is a write. So the command parks on humanVerdict. Compose applies it and the applied cell reads demonstrated ≠ proved. The stronger word is not offered: MintClaim("proved") fails assertLegalCommand because five MUST-PROVE items are open.

Counterpoint

13/13 is a toy-scale demonstration by bounded enumeration. The universal-property check is narrower than the pre-registered exhaustive bound; the script records that as a protocol deviation. "Demonstrated ≠ proved" is not modesty, it is the claims ladder: MUST-PROVE 1–5 remain open, and nothing on this page closes them.
The judge here is a twin, and this page never asks it. The checks are booleans read from a recorded file; the human verdict is three buttons. No key, no network. A live TypeSafe call is a claim this page does not make.

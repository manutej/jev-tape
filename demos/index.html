The tape meets the wiring.

One repo says a codebase is a module of systems: units known only through their interfaces, glued along shared ports, shipped to a model as a wiring pack. The other says a judged process is typed questions, one answer map per gate, code that routes, and a tape that remembers. Put a pack in the place of a domain command and every construct on one side has a partner on the other. These ten demos are those partners, built from the experiments' own numbers.

How to read them. Each page is one instrument: controls on the left, a custom drawing on the right, and the tape pinned at the bottom recording what happened. Every number on a page ends in a table that names its file. Pages never call the judge themselves: where a green pill shows, the answers were recorded once from a real pinned call and replayed; elsewhere a deterministic twin stands in.

The seam, row by row

Each demo carries one jev construct to one wiring construct and says which speed path it runs on. The right-hand column is the measured thing the demo shows, not the twin's opinion.

How these were built

The meta-suite ran in its usual order: a meta-plan with typed work units and parallel lanes, a reusable meta-prompt for “a jev demo”, a composition gate that checks each page against the plan mechanically, and a provenance ledger. The documents are in the repo beside the demos.

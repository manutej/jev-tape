A claim is a fork with three exits.

The wiring repo keeps a claims ladder: what its experiments may say and what they may not. Every rung is a claim with evidence pointers, and every claim is a closed fork: verified, contradicted, or unsupported. That is lane 2. Claim text and recorded evidence go in, one of three words comes out, and the lane never writes the claim. This demo walks the ten rungs with one request and stamps each one. When the pill is green the stamps are the real judge's, recorded once; otherwise a twin returns the repo's own discipline.

The intersection. wiring-and-the-whole is disciplined about what it may claim: demonstrated is not proved, consistency is not correctness. jev-tape has a lane for exactly that discipline. Put the ladder in the lane and each rung gets a stamp it cannot give itself.

What the tape shows

Lane 2 is a judge job because the option set is closed: three words, no fourth. It is not a code job because the match between a sentence and a quotation is not deterministic. So one request carries ten Choice questions, each with the claim and its evidence snippets as state, and the tape records the answer map once, with one POST.

The walk that follows is code reading the recorded answers. Each rung gets a code cell with its stamp; nothing is posted again. There is no apply cell at the end, because the lane does not write the claim. Whoever edits the README does that, on the human's side of the line.

Rungs above the highest verified rung are drawn dashed, and a contradicted rung is drawn broken. The ladder is only as high as its last verified rung. Walk it to see where that is.

The twin returns exactly what the repo's claims discipline records for each claim. The recorded judge does not have to agree with it, and where it does not, the stamp shows the judge's answer and the reasons list names the difference. That difference is the finding: a lane that only ever echoed the README would not be worth a POST.

Counterpoint

The lane checks a claim against recorded evidence. It does not re-run the experiment. A verified rung inherits every caveat in its source: toy scale, one corpus, one handler family, questions written by the same author as the packs. "Verified" means the evidence on file says what the claim says, not that the claim is true of the world.
Recorded once, or a twin. When the pill is green, the ten answers shown are recorded from one real call on this page's default state and replayed from data/recorded.js. Otherwise a twin returns the verdict the repo's own claims discipline records for each claim, with a peaked probability, through the same wire shape and contract checks as the real client. This page never calls the judge itself: no key, no network.

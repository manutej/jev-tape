The tape is itself a module of systems.

Run the wiring extractor over jev-tape's own source and you get six units, 35 ports, six edges. The same pack format the experiments used for Fineract describes the tool that gates them: explicit 380 tokens, factored 280, real counts. One src unit fetches and reads the key. Nothing in the workflow imports it. That seam is the three planes, drawn.

The intersection. wiring-and-the-whole says a large codebase is a module of systems: units known only through interfaces, glued by typed interaction patterns. jev-tape is a codebase. So it has a wiring pack, and the pack shows where the judge is allowed to live.

What the tape shows

Every cell on this tape is kind: code. Extracting ports is a regex. Gluing two units along their shared symbols is a union of two tables with five identifications. Checking κ is a lookup: does any identified symbol carry two different signatures? None does, so κ stays silent. Three deterministic steps, zero POSTs, path 0.

The pack has a seam. Four units never fetch: domain, colors, typesafe.contract, and the workflow that would import them. One unit does: typesafe.client. It is the Activity, and the tape at the bottom of every demo is the record of its results. A workflow that imported the client would put the judge in replayable code, and a RED could come back GREEN on replay. The extractor makes that import visible as an edge, so its absence is checkable.

Switch the paper between explicit and factored. Both re-expand to the same edge list; the factored one is 100 tokens shorter because six rows share one motif. The break-even line under the paper is the E2 rule applied to these six units.

Counterpoint

This extractor is regex-level. It sees export statements and named imports, nothing else: no re-exports, no dynamic imports, no types used without import. That is the same deliberate subset E2 used. Six units is a toy. The token counts are real counts of a toy.
The judge here is a twin, and this page never even asks it. The point of a path-0 page is that nothing here needs a judge: the questions are answered by lookup. No key, no network. A live TypeSafe call is a claim this page does not make.

## Doctrine you may quote (verbatim from jev-tape)

- Loop: `assertLegalCommand → qualifyTask → gate → propose in memory → qualifyOutput → gate → applyCommand`. Apply is the first domain write and only after both gates GREEN, or human compose.
- Three planes: "Operad names questions. TypeSafe answers them. Temporal remembers the answer across crash, wait, and replay." "Operad must not fetch. TypeSafe must not apply. Temporal must not invent questions."
- Four speed paths: 0 code (deterministic; no TypeSafe, no Temporal) · 1 batch judge (one POST, many questions) · 2 rank then read (shortlist POST recorded, then the expensive LLM) · 3 tape (crash, wait, worklist, C10; reuse recorded answers).
- "Replay does not call TypeSafe again." "If TypeSafe sat in Workflow code, a RED Capture could come back GREEN on replay and apply."
- C10: Complete, Trash, ResolveWaiting (and send, merge-to-default) park on Signal `humanVerdict {compose|escalate|refuse}` even when the gate is GREEN.
- composeAnswers is code. "Judge Choice cannot override a local RED." Dual axis: θ is P(fail-closed gate is GREEN); top_prob_floor is pack peakedness; never the same number. "Low confidence is not ask Jev again. It is AMBER / Signal."
- Three lanes: 1 decision gate (before send/pay/merge/cancel) · 2 claim verify (claim + evidence → verified | contradicted | unsupported) · 3 context screen (untrusted text → pass | review | block | skip; "Replay must not re-ingest a recorded BLOCK as PASS").
- Anti-jobs: code computes; LLMs create; Jev decides at closed forks; humans approve irreversible side effects. "A fork with an open option set is an LLM job, not a Jev job."
- Two clocks: harness occupancy (seconds: screen tool output, route, groundedness; goal fewer LLM calls) vs process occupancy (hours to weeks: qualify → propose → qualify → apply last; goal the write that cannot happen twice).
- FIRE (unrepresentable): fifth Clarify arm; god-TaskWorkflow; TypeSafe fused into the kernel; judge overriding local RED; jev-latest in production; TypeSafe again on replay.

- "A large codebase is not a pile of files. It is a module of systems — units known only through interfaces, glued by typed interaction patterns."
